How to run a mad minute

A mad minute is a short timed drill: answer as many arithmetic problems as you can in one minute. It builds fluency, meaning answering a fact without working it out, which frees up thinking for harder maths later. Here is a simple way to run one at home or in a classroom.

Before you start

  • Pick a range the child can mostly answer. If they are stuck on most of it, step down to an easier sheet; the drill is for facts they nearly know.
  • Use a ready-made worksheet or make one for the exact numbers you want to practise.
  • Print the answer key on its own page so marking takes seconds.

Running it

  1. Sheets face down, pencils ready. Say "go" and start the timer.
  2. Work in order and skip anything that takes too long, then come back if there is time.
  3. When the minute ends, pencils down. Mark together, and count the correct answers (not how far they got).
  4. Write the score on the progress tracker.

Keeping it useful

  • Compete against yesterday, not each other. Comparing children's scores turns a confidence builder into a source of dread.
  • Little and often. A minute a day beats a long session once a week.
  • Look at the misses. If the same facts keep going wrong, practise those alone with the chart and a single times table page before another full sheet.
  • Move up when it is easy. When most of a sheet is right before time runs out, widen the range or add an operation.
